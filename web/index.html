连续时间稳定 ≠ 离散稳定

把增量式算法写成 ODE 只完成了一半：算法本身就是该 ODE 的一个数值积分格式。 ODE 的特征值只要落在左半平面就稳定，而离散迭代要求 ηλ 落在一个有限的圆盘里。 这条缝隙是"调小学习率救不回来"的那些不稳定的来源。下面四个演示把它拆开看。

01时间重标定：离散点必须落在 ODE 流上

取 x_{k+1} = x_k − η(Ax_k − b)，即二次目标的梯度下降。对应的平均场 ODE 是 ẋ = −A(x − x*)。左图把离散迭代点与 ODE 精确流画在同一张相图上；右图是误差的衰减。 唯一要做的事是把时间换成 t = kη，否则两条曲线会差一个 η 的时间尺度。

02稳定域不是一个半平面，而是一个圆盘

连续时间只要 Re λ < 0；前向 Euler 要求 |1 + ηλ| < 1， 在复平面上这是一个以 −1/η 为圆心、半径 1/η 的圆盘 —— 它在原点与虚轴相切。 拖动任意 λ 点，橙色代表"连续稳定但离散不稳定"。

步长 η

0.300

η 越小，圆盘越大，容错越宽；但迭代次数也线性变多 —— 这就是"精度换步长"的原始形态。

03缝隙现场：Heavy-ball 的 Hopf 分岔

动量法的连续极限是 ẍ + a·ẋ + ∇f = 0，阻尼 a = (1−β)/√η： 只要 β < 1 就 a > 0，ODE 无条件稳定。 但离散化的特征值 μ 由 μ² − (1+β−ηλ)μ + β = 0 给出，需要 0 < ηλ < 2(1+β)。左图是 μ 随 η 移动的根轨迹，右图是实际迭代。

04噪声地板：ODE 不给方差，但给了它的一阶项

噪声不移动 h(x*) = 0，所以不改变 ODE 的平衡点。对 θ_{k+1} = θ_k + ηφ(y − φᵀθ)，误差递推是 e_{k+1} = (1−ηs²)e_k + ηs·ε，稳态方差有闭式 V = ησ²/(2 − ηs²) —— 正比于 η。所以常数步长永远只收敛到一个 O(√η) 的邻域。
